The instinct is to stand on each 1 and walk until you find a 0 — one whole queue per cell, which is O((mn)²). Turn it round: put every 0 in the queue before the first pop and a single sweep hands every cell its distance to the nearest source. This is not reachability — every cell is reached; the question is how far. There is a genuinely different correct machine here too, the two-pass DP, and watching its one-pass cousin fail is the shortest argument for why BFS is the safer default.

BFS: O(m·n) time, O(m·n) queue  ·  two-pass DP: O(m·n) time, O(1) extra  ·  one BFS per 1: O((m·n)²)
Seeding every 0 at once is the same inversion LC 130 makes with the border: ask the sources the question, not the cells. The two-pass DP is correct and cheaper on memory, but it is correct only because both sweeps run — and nothing in the code tells you when you have written just one. BFS has no half-correct form, which is why it is the safer default.
