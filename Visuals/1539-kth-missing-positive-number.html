Kth Missing Positive Number / visualized

In a strictly increasing array of positives, index i would hold the value i+1 if nothing were missing. So the drift arr[i] − (i+1) is the count of positives already skipped before arr[i] — and that count never decreases. Binary search for the first index where the drift reaches k: lo lands on how many array values the answer has passed, and the answer is k + lo.
