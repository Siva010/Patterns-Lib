Index-vs-Value Correspondence LeetCode 540

Single Element in a Sorted Array / visualized

Nothing here searches for a value. Every element is paired except one, so before the singleton a pair opens at every even index and the identity nums[i] == nums[i^1] holds everywhere; after it, every pair has slid one slot right and that identity fails everywhere. So the array is split into an agreeing prefix and a broken suffix — monotone, therefore binary-searchable. Snap mid down to an even index, ask nums[mid] == nums[mid+1], and discard the half that is still intact.
