Binary Search — Rightmost Satisfying Index LeetCode 981

Time Based Key-Value Store / visualized

set is called with strictly increasing timestamps, so each key's list is already sorted — the store is a hash map from key to that list, and nothing more. get(key, t) is where the work is, and it is not an equality search: t usually is not in the list at all. The predicate ts[i] ≤ t is true on a prefix and false after it, and we want the last true index. So mid that satisfies it is not an exit — it is a candidate to record before pushing lo further right. When the prefix of true is empty, nothing is ever recorded, and the answer is the empty string.
