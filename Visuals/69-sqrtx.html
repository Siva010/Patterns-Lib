Binary Search on the Answer — Continuous, in Integer Form LeetCode 69

Sqrt(x) / visualized

There is no array. The search space is the answer, 0 .. x, and the predicate mid*mid ≤ x is true on a prefix and false forever after — the only property binary search needs. Swap the loop for while (hi − lo > 1e-9) and the exact same shape searches a genuinely continuous answer; the integer version here is that template with the tolerance set to one. Two things make this Easy problem not trivial: mid*mid overflows int, and the loop necessarily lands on the floor, not the root.
