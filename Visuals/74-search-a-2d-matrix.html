Step 1 of a three-page lesson (74 → 240 → 378): three problems that look like the same problem and need three completely different machines. Here the flattening works — each row is sorted and every row starts above the previous row's last value, so the matrix already is one sorted array of length m×n. Run an ordinary binary search over [0, m×n) and translate the index with row = idx / n, col = idx % n.
